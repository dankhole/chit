watchOS Improvements

Tot 2.0

August 2025

New Features

  • Custom Smart Bullets:
    • Assign symbols or standard Emoji to act as Smart Bullets
    • Create up to eight custom smart bullets via Settings > Appearance
    • Assign Custom Smart Bullets to Quick Key slots for instant access
  • Text Dividers:
    • Eight divider styles to choose from via the symbol picker
    • Assign text dividers to Quick Key slots for easy use
    • Keyboard shortcut: Ctrl-Minus to add a new divider
    • Dividers can be cut/copy/pasted at will
    • Uses Markdown horizontal rules
    • [Yay Funk_Shui & Stragen!]
  • Automatic indents:
    • Lines that begin with a bullet or Smart Bullet will automatically indent text that’s wider than the window
    • The Cmd-[ and Cmd-] keyboard shortcuts can be used to indent any selection
    • Lines that begin with a space will use that for indentation, otherwise tabs are used
    • Works with plain text: great for writing in Markdown [Yay Gruber!]

Improvements

  • Improved text handling & bug fixes:
    • Paste as Plain Text can now strip Markdown and works better with rich text
    • Fixed a bug where bold stuck around after creating newlines [Yay Nathan!]
    • Improved handling of styling information while using drag & drop
    • Fixed a styling bug when pasting Smart Bullets in plain text mode
    • Fixed a big bug when opening links beginning with “HTTP”
    • New "Selected Dot" action for Shortcuts [Yay pseudometa!]
  • Updated User Manual:
    • Removed Twitter links because screw those guys
    • Updated for new features and settings
    • Added information and links for advanced users

macOS Improvements

    • Overview for apps on iOS and watchOS
    • Better help links and support site access
  • Improved Editing:

    • Added menu item for Remapping Keyboard Shortcuts
  • Window, Dock, and menu bar:
